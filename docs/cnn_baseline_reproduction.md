# CNN Baseline Reproduction

This page records the exact tutorial CNN baseline as a reproducible reference run.
It preserves the original notebook model while moving the run into package code so
metrics, predictions, and run metadata can be saved consistently.

## Reference Task

The baseline is binary promoter classification from SBOL-derived sequence
windows. The tutorial converts the numeric `target` into a binary class using
the median target value from the materialized rows.

This is a tutorial reference, not the final shared benchmark. The main model
comparison dataset remains the predefined `EP_DNA_BERT2_genomic_order` split
recorded in `config-examples/benchmarks/`.

## Dataset And Labels

- Data directory: `data/sbol_data`
- File selection: first 40 files from `sorted(Path(data_dir).glob("sample_design_*.xml"))`
- Materialization: `seqtrainer.data.sbol.build_dataset_from_files`
- Sequence column: `sequence`
- Numeric target column: `target`
- Binary label rule: `label = target >= median(target)`
- Split rule: `train=0.7`, `validation=0.15`, `test=0.15`
- Split seed: `42`

The median threshold is saved in `manifest.json` for every run.

## Preprocessing

- Fixed sequence length: 120
- Padding/trimming: `seqtrainer.transforms.dna.pad_or_trim`
- Encoding: one-hot over `A`, `C`, `G`, `T`, and `N`
- PyTorch tensor shape: `[batch, channels, length]`

## Model Architecture

The model matches the tutorial notebook:

```text
Conv1d(5, 32, kernel_size=7, padding=3)
ReLU
MaxPool1d(kernel_size=2)
Conv1d(32, 64, kernel_size=5, padding=2)
ReLU
AdaptiveMaxPool1d(1)
Flatten
Linear(64, 32)
ReLU
Linear(32, 2)
```

## Training

- Loss: `CrossEntropyLoss`
- Optimizer: `Adam`
- Learning rate: `1e-3`
- Batch size: `16`
- Cycles: `10` by default
- Device: CPU by default
- Seed: `42`

The original notebook fixed only the split seed. The reproducible runner also
sets Python, NumPy, and PyTorch seeds before model initialization and DataLoader
shuffling. This change is needed so baseline metrics can be regenerated by
another researcher.

## Run Locally

```bash
seqtrainer reproduce-cnn-baseline \
  --data-dir data/sbol_data \
  --output-dir outputs/cnn_baseline_reference
```

For a quicker smoke run:

```bash
seqtrainer reproduce-cnn-baseline \
  --data-dir data/sbol_data \
  --output-dir outputs/cnn_baseline_smoke \
  --cycles 1 \
  --max-files 12
```

## Output Artifacts

The runner writes:

- `config.json`: resolved run parameters
- `manifest.json`: dataset, split, preprocessing, architecture, and training metadata
- `metrics.json`: split-wise metrics
- `metrics.csv`: tabular split-wise metrics
- `history.csv`: cycle-wise train/validation loss and accuracy
- `predictions.csv`: split-wise labels, probabilities, and predictions

These artifacts provide the reference point for later improved CNN, DNABERT2,
and iPro-MP comparisons.

## Run The Shared CSV Benchmark

The real model comparison should use the three predefined CSV split files from
the promoter classification dataset:

- `train_EP_DNA_BERT2_genomic_order.csv`
- `eval_EP_DNA_BERT2_genomic_order.csv`
- `test_EP_DNA_BERT2_genomic_order.csv`

The default config expects these files under:

```text
data/promoter_classification/
```

Run the CNN on those splits with:

```bash
seqtrainer run-cnn-benchmark \
  --config config-examples/benchmarks/cnn.toml
```

The command trains only on `train`, selects the decision threshold using the
validation/eval split by MCC, and then reports test metrics using that validation
threshold. This avoids choosing a threshold from the test set.
